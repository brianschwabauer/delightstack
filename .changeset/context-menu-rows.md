ContextMenu rows line up like a native menu, with labels in one left-aligned column (rows without an icon keep an empty icon column when another row has one), group hairlines on the row inset, and shortcuts drawn as quiet keycaps that print each key the way the platform writes it (⇧, ⌘ on Apple and Ctrl elsewhere, ↵, ⌫, arrows), including a new `Mod` key name for the platform's main modifier; CommandPalette's shortcut keys use the same caps and glyphs.
