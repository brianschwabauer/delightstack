ContextMenu rows line up like a native menu: labels start in one left-aligned column (rows without an icon keep an empty icon column when another row has one), icons and group hairlines share the row's inset in both regular and dense menus, and shortcut keys are joined with "+" (Shift+Ctrl+G) except on Apple platforms, where the glyphs stay together (⇧⌘G).
