### Custom Formatter

Override the default `Intl.NumberFormat` with a custom function for compact display.

```svelte
<Counter
  value={1500000}
  format={(n) => {
    if (n >= 1000000) return (n / 1000000).toFixed(1) + 'M';
    if (n >= 1000) return (n / 1000).toFixed(1) + 'K';
    return n.toString();
  }}
/>
```

### Locale-Aware Formatting

Number separators adapt to the specified locale.

```svelte
<!-- German: 1.234,56 -->
<Counter value={1234.56} locale="de-DE" decimals={2} />

<!-- US: 1,234.56 -->
<Counter value={1234.56} locale="en-US" decimals={2} />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number` | required | Target number to display |
| `duration` | `number` | `1000` | Animation duration in milliseconds |
| `delay` | `number` | `0` | Delay before animation starts (ms) |
| `decimals` | `number` | `0` | Number of decimal places |
| `prefix` | `string` | - | Text before the number (e.g., "$") |
| `suffix` | `string` | - | Text after the number (e.g., "%") |
| `format` | `(n: number) => string` | - | Custom formatter (overrides Intl.NumberFormat) |
| `animation` | `'count' \| 'flip' \| 'fade'` | `'count'` | Animation style |
| `separator` | `boolean` | `true` | Use locale thousands separator |
| `locale` | `string` | - | BCP 47 locale for number formatting |
| `easing` | `(t: number) => number` | ease-out cubic | Animation easing function |
| `skeleton` | `boolean` | `false` | Show loading skeleton |
| `id` | `string` | auto | Element ID |
| `class` | `string` | `''` | Additional CSS classes |

## Events

| Event | Detail | Description |
|-------|--------|-------------|
| `oncomplete` | - | Fired when the animation finishes |

## Accessibility

- Element has `aria-live="polite"` so screen readers announce value changes
- `role="img"` with a computed `aria-label` including prefix, value, and suffix
- Final value is always accessible in the DOM (animation is visual only)
- `prefers-reduced-motion` disables all animation -- the final value is shown immediately
- `font-variant-numeric: tabular-nums` prevents layout shift during animation
- Animation is triggered by `IntersectionObserver` -- starts only when the element scrolls into view
- On the server (SSR), the final formatted value is rendered immediately with no animation
