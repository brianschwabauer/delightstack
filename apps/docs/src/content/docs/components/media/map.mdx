---
title: Map
description: An interactive map component with a pluggable provider architecture, marker support, custom popups, and automatic dark mode tile switching.
---

## Import

```svelte
import { Map, leafletProvider } from '@delightstack/components';
import type { MapMarker, MapProvider, MapInitOptions } from '@delightstack/components';
```

## Peer Dependency

Map requires `leaflet` as a peer dependency (loaded lazily at runtime):

```bash
pnpm add leaflet
```

You also need to include the Leaflet CSS in your app (e.g. in your layout):

```html
<link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css" />
```

## Basic Usage

```svelte
<script>
  import { Map, leafletProvider } from '@delightstack/components';

  let center = $state<[number, number]>([51.505, -0.09]);
  let zoom = $state(13);
</script>

<Map provider={leafletProvider()} bind:center bind:zoom />
```

## Examples

### With Markers

Display markers on the map with click handling.

```svelte
<script>
  import { Map, leafletProvider } from '@delightstack/components';
  import type { MapMarker } from '@delightstack/components';

  const markers: MapMarker[] = [
    { position: [51.505, -0.09], title: 'London' },
    { position: [48.856, 2.352], title: 'Paris' },
    { position: [52.52, 13.405], title: 'Berlin' },
  ];
</script>

<Map
  provider={leafletProvider()}
  {markers}
  fitMarkers
  onmarkerclick={({ marker }) => console.log('Clicked', marker.title)}
/>
```

### Custom Popup Content

Render custom HTML popups when markers are clicked using the `popup` snippet.

```svelte
<Map provider={leafletProvider()} {markers} fitMarkers>
  {#snippet popup(marker)}
    <div>
      <strong>{marker.title}</strong>
      {#if marker.data?.description}
        <p>{marker.data.description}</p>
      {/if}
    </div>
  {/snippet}
</Map>
```

### Custom Tile URLs

Provide custom tile URLs for light and dark themes.

```svelte
<Map
  provider={leafletProvider({
    tileUrl: 'https://{s}.tile.openstreetmap.fr/hot/{z}/{x}/{y}.png',
    darkTileUrl: 'https://{s}.basemaps.cartocdn.com/dark_all/{z}/{x}/{y}{r}.png',
  })}
  center={[40.7128, -74.006]}
  zoom={12}
/>
```

### Static (Non-Interactive) Map

Disable panning and zooming for a static map display.

```svelte
<Map
  provider={leafletProvider()}
  center={[51.505, -0.09]}
  zoom={15}
  interactive={false}
  height="200px"
/>
```

### Skeleton Loading

```svelte
<Map skeleton height="400px" />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `provider` | `MapProvider` | `leafletProvider()` | Map provider adapter |
| `center` | `[number, number]` | `[0, 0]` | Map center `[lat, lng]` (`$bindable`) |
| `zoom` | `number` | `10` | Zoom level (`$bindable`) |
| `markers` | `MapMarker[]` | `[]` | Markers to display on the map |
| `cluster` | `boolean` | `false` | Enable marker clustering (requires `leaflet.markercluster`) |
| `interactive` | `boolean` | `true` | Enable pan/zoom interaction |
| `fitMarkers` | `boolean` | `false` | Auto-fit bounds to show all markers |
| `fitPadding` | `number` | `50` | Padding in pixels when fitting to markers |
| `height` | `string` | `'400px'` | Container height |
| `skeleton` | `boolean` | `false` | Show loading skeleton |
| `id` | `string` | auto | Element ID |
| `class` | `string` | `''` | Additional CSS classes |
| `element` | `HTMLElement` | `undefined` | Bindable reference to the root element (`$bindable`) |
| `map` | `unknown` | `undefined` | Bindable reference to the underlying provider map instance (`$bindable`) |
| `popup` | `Snippet<[marker: MapMarker]>` | `undefined` | Custom popup content snippet |

## Events

| Event | Detail | Description |
|-------|--------|-------------|
| `onmarkerclick` | `{ marker: MapMarker }` | Fires when a marker is clicked |
| `onmove` | `{ center: [number, number], zoom: number }` | Fires when the map is panned or zoomed |
| `onclick` | `{ latlng: [number, number] }` | Fires when the map background is clicked |
| `onload` | `{ map: unknown }` | Fires when the map provider initializes |

## Types

### MapMarker

```typescript
interface MapMarker {
  position: [number, number];
  title?: string;
  icon?: string;
  data?: Record<string, unknown>;
}
```

### MapProvider

```typescript
interface MapProvider {
  init(container: HTMLElement, options: MapInitOptions): Promise<unknown>;
  destroy(): void;
  setCenter(center: [number, number]): void;
  setZoom(zoom: number): void;
  addMarker(marker: MapMarker, onClick?: () => void): unknown;
  removeMarker(markerRef: unknown): void;
  clearMarkers(): void;
  fitToMarkers(padding: number): void;
  on(event: string, handler: Function): void;
}
```

### MapInitOptions

```typescript
interface MapInitOptions {
  center: [number, number];
  zoom: number;
  interactive: boolean;
}
```

### leafletProvider

The default provider factory for Leaflet maps. Automatically switches between light and dark tile layers based on `prefers-color-scheme`.

```typescript
function leafletProvider(options?: {
  tileUrl?: string;
  darkTileUrl?: string;
}): MapProvider;
```

## Accessibility

- Interactive maps use `role="application"` with `aria-label="Interactive map"`
- Non-interactive maps use `role="img"` with `aria-label="Map"`
- Interactive mode adds `tabindex="0"` for keyboard focus
- Focus-visible outline on the map container
- Marker titles are passed through to the underlying map provider as tooltips
