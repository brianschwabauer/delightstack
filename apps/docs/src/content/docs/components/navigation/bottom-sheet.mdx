## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | `false` | Controls visibility (`$bindable`) |
| `snapPoints` | `number[]` | `[0.5, 1]` | Snap points as fractions of viewport height (0-1) |
| `defaultSnap` | `number` | `0` | Default snap point index when opening |
| `snap` | `number` | `0` | Current snap point index (`$bindable`) |
| `dismissible` | `boolean` | `true` | Whether the sheet can be dismissed by dragging down |
| `showHandle` | `boolean` | `true` | Whether to show the drag handle |
| `showBackdrop` | `boolean` | `true` | Whether to show the backdrop overlay |
| `blocking` | `boolean` | `true` | Whether to lock body scroll when open |
| `id` | `string` | auto | Element ID |
| `class` | `string` | `''` | Additional CSS classes |
| `children` | `Snippet` | `undefined` | Main scrollable content |
| `header` | `Snippet` | `undefined` | Header content rendered below the handle |

## Events

| Event | Detail | Description |
|-------|--------|-------------|
| `onopen` | none | Fires when the sheet opens |
| `onclose` | none | Fires when the sheet closes |
| `onsnap` | `{ index: number, height: number }` | Fires when the sheet snaps to a point |

## Accessibility

- `role="dialog"` with `aria-modal="true"` on the sheet
- Drag handle uses `role="slider"` with `aria-label="Sheet height"` and aria-value attributes
- **Escape** dismisses the sheet (when `dismissible` is true)
- Backdrop click dismisses the sheet (when `dismissible` is true)
- Body scroll is locked when `blocking` is true
- Spring-physics animation with rubber banding at extremes
- Scroll-aware drag: content scrolls at the highest snap point, transitions to sheet drag when pulling down at scroll top
- Respects `prefers-reduced-motion`
