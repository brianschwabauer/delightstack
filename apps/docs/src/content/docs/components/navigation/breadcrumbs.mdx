## Examples

### Collapsed Middle Items

When the trail is long, collapse middle items into an ellipsis dropdown.

<ComponentPreview code={`<script>
${'  '}import { Breadcrumbs } from '@delightstack/components';

${'  '}${'  '}{ label: 'Category', href: '/cat' },

${'  '}${'  '}{ label: 'Model', href: '/cat/sub/brand/model' },
${'  '}${'  '}{ label: 'Product' },

### Click Handler

React to breadcrumb clicks without relying solely on native navigation.

<ComponentPreview code={`<script>
${'  '}import { Breadcrumbs } from '@delightstack/components';

${'  '}const items = [
${'  '}${'  '}{ label: 'Home', href: '/' },
${'  '}${'  '}{ label: 'Products', href: '/products' },
${'  '}${'  '}{ label: 'Detail' },
${'  '}];

${'  '}let lastClicked = $state('');
</script>

<Breadcrumbs
${'  '}{items}
${'  '}showHome={false}
${'  '}onclick={({ item, index }) => {
${'  '}${'  '}lastClicked = \`Clicked "\${item.label}" (index \${index})\`;
${'  '}}}
/>`}>
	<BreadcrumbsClickDemo client:load />
</ComponentPreview>

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | `BreadcrumbItem[]` | `[]` | The breadcrumb items to display |
| `maxItems` | `number` | `undefined` | Max visible items before collapsing middle items into an ellipsis dropdown |
| `showHome` | `boolean` | `true` | Whether to show a home icon as the first breadcrumb |
| `homeHref` | `string` | `'/'` | The href for the home breadcrumb |
| `size` | `'0' \| '1' \| '2' \| '3'` | `'1'` | Size of the breadcrumbs |
| `skeleton` | `boolean` | `false` | Show skeleton loading state |
| `skeletonCount` | `number` | `3` | Number of skeleton placeholder items |
| `id` | `string` | auto | Element ID |
| `class` | `string` | `''` | Additional CSS classes |
| `children` | `Snippet` | `undefined` | Custom rendering snippet (replaces default rendering) |
| `separator` | `Snippet` | `undefined` | Custom separator snippet |

## Events

| Event | Detail | Description |
|-------|--------|-------------|
| `onclick` | `{ item: BreadcrumbItem, index: number }` | Fires when a breadcrumb item is clicked |

## Types

### BreadcrumbItem

```typescript
interface BreadcrumbItem {
  label: string;
  href?: string;
}
```

## Accessibility

- Uses `<nav>` with `aria-label="Breadcrumb"`
- Semantic `<ol>` list for the breadcrumb trail
- Last item has `aria-current="page"`
- Home icon includes screen-reader-only text (`<span class="sr-only">`)
- Ellipsis dropdown button has `aria-label="Show hidden breadcrumbs"` and `aria-expanded`
- Focus-visible outlines on all links and buttons
- Automatically generates Schema.org `BreadcrumbList` JSON-LD for SEO
