## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | `false` | Controls visibility (`$bindable`) |
| `right` | `boolean` | `false` | Position the drawer on the right edge |
| `top` | `boolean` | `false` | Position the drawer on the top edge |
| `bottom` | `boolean` | `false` | Position the drawer on the bottom edge |
| `push` | `boolean` | `false` | Use push mode: content shifts, no backdrop |
| `persistent` | `boolean` | `false` | Use persistent mode: always visible, part of layout flow |
| `width` | `string` | `'280px'` | Width of the drawer (used for left/right positions) |
| `height` | `string` | `'280px'` | Height of the drawer (used for top/bottom positions) |
| `closeOnOutsideClick` | `boolean` | `true` | Whether clicking outside the drawer closes it |
| `closeOnEscape` | `boolean` | `true` | Whether pressing Escape closes the drawer |
| `breakpoint` | `string` | `undefined` | Media query breakpoint for switching between persistent and overlay modes |
| `id` | `string` | auto | Element ID |
| `class` | `string` | `''` | Additional CSS classes |
| `children` | `Snippet` | `undefined` | Main drawer content |
| `header` | `Snippet` | `undefined` | Header content |
| `footer` | `Snippet` | `undefined` | Footer content |

## Events

| Event | Detail | Description |
|-------|--------|-------------|
| `onopen` | none | Fires when the drawer opens |
| `onclose` | none | Fires when the drawer closes |

## Accessibility

- Overlay mode: `role="dialog"` with `aria-modal="true"`, focus trapped via `focusTrap`
- Persistent mode: rendered as `<aside>` with `aria-label="Side panel"`
- **Escape** closes the drawer (when `closeOnEscape` is true and not persistent)
- Backdrop click closes the drawer (when `closeOnOutsideClick` is true)
- Body scroll is locked in overlay mode
- Focus is restored to the previously focused element on close
- Swipe-to-close gesture on touch devices (30% threshold of drawer size)
- CSS transition animation with `prefers-reduced-motion: reduce` support
