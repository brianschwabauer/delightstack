---
title: Menu
description: A dropdown menu with keyboard navigation, checkbox items, radio groups, grouped sections, separators, and shortcut hints.
---

## Import

Menu uses a compound component pattern. All sub-components are re-exported from the same module.

```svelte
import {
  Menu,
  MenuItem,
  MenuSeparator,
  MenuGroup,
  MenuCheckboxItem,
  MenuRadioGroup,
  MenuRadioItem,
} from '@delightstack/components';
import type { MenuContext } from '@delightstack/components';
```

## Basic Usage

```svelte
<script>
  import { Menu, MenuItem, MenuSeparator, Button } from '@delightstack/components';

  let menuOpen = $state(false);
  let triggerEl = $state<HTMLElement>();
</script>

<Button bind:element={triggerEl} onclick={() => menuOpen = !menuOpen}>
  Actions
</Button>

<Menu bind:open={menuOpen} trigger={triggerEl}>
  <MenuItem onclick={() => console.log('Edit')}>Edit</MenuItem>
  <MenuItem onclick={() => console.log('Duplicate')}>Duplicate</MenuItem>
  <MenuSeparator />
  <MenuItem danger onclick={() => console.log('Delete')}>Delete</MenuItem>
</Menu>
```

## Examples

### With Shortcuts and Badges

Display keyboard shortcut hints and badges on menu items.

```svelte
<Menu bind:open={menuOpen} trigger={triggerEl}>
  <MenuItem shortcut="Ctrl+C" onclick={handleCopy}>Copy</MenuItem>
  <MenuItem shortcut="Ctrl+V" onclick={handlePaste}>Paste</MenuItem>
  <MenuSeparator />
  <MenuItem badge="3" onclick={handleNotifications}>Notifications</MenuItem>
</Menu>
```

### Grouped Items

Organize related items under labeled groups.

```svelte
<Menu bind:open={menuOpen} trigger={triggerEl}>
  <MenuGroup label="File">
    <MenuItem onclick={handleNew}>New</MenuItem>
    <MenuItem onclick={handleOpen}>Open</MenuItem>
    <MenuItem onclick={handleSave}>Save</MenuItem>
  </MenuGroup>
  <MenuGroup label="Edit">
    <MenuItem onclick={handleUndo}>Undo</MenuItem>
    <MenuItem onclick={handleRedo}>Redo</MenuItem>
  </MenuGroup>
</Menu>
```

### Checkbox Items

Toggle-able menu items with a checked state.

```svelte
<script>
  let showGrid = $state(true);
  let showRulers = $state(false);
</script>

<Menu bind:open={menuOpen} trigger={triggerEl}>
  <MenuGroup label="View">
    <MenuCheckboxItem bind:checked={showGrid}>Show Grid</MenuCheckboxItem>
    <MenuCheckboxItem bind:checked={showRulers}>Show Rulers</MenuCheckboxItem>
  </MenuGroup>
</Menu>
```

### Radio Group

Single-selection items within a radio group.

```svelte
<script>
  let theme = $state('system');
</script>

<Menu bind:open={menuOpen} trigger={triggerEl}>
  <MenuRadioGroup bind:value={theme}>
    <MenuRadioItem value="light">Light</MenuRadioItem>
    <MenuRadioItem value="dark">Dark</MenuRadioItem>
    <MenuRadioItem value="system">System</MenuRadioItem>
  </MenuRadioGroup>
</Menu>
```

### Disabled Items

```svelte
<Menu bind:open={menuOpen} trigger={triggerEl}>
  <MenuItem onclick={handleSave}>Save</MenuItem>
  <MenuItem disabled>Save As... (Pro)</MenuItem>
</Menu>
```

### Custom Placement

Position the menu relative to the trigger using Floating UI placements.

```svelte
<Menu bind:open={menuOpen} trigger={triggerEl} placement="right-start">
  <MenuItem>Option A</MenuItem>
  <MenuItem>Option B</MenuItem>
</Menu>
```

## Props

### Menu (Container)

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `open` | `boolean` | `false` | Controls visibility (`$bindable`) |
| `trigger` | `HTMLElement` | `undefined` | The trigger element the menu is anchored to |
| `placement` | `Placement` | `'bottom-start'` | Popover placement relative to the trigger (Floating UI) |
| `close_on_select` | `boolean` | `true` | Whether the menu closes when an item is selected |
| `size` | `'0' \| '1' \| '2' \| '3'` | `'1'` | Size of the menu items |
| `id` | `string` | auto | Element ID |
| `class` | `string` | `''` | Additional CSS classes |
| `children` | `Snippet` | `undefined` | Menu content (MenuItem, MenuGroup, etc.) |

### MenuItem

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `shortcut` | `string` | `undefined` | Keyboard shortcut hint displayed on the right |
| `badge` | `string \| number` | `undefined` | Badge displayed on the right |
| `disabled` | `boolean` | `false` | Whether the item is disabled |
| `danger` | `boolean` | `false` | Style as a destructive action |
| `children` | `Snippet` | `undefined` | Item label content |

### MenuCheckboxItem

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `checked` | `boolean` | `undefined` | Whether the checkbox is checked (`$bindable`) |
| `disabled` | `boolean` | `false` | Whether the item is disabled |
| `children` | `Snippet` | `undefined` | Item label content |

### MenuRadioGroup

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | `undefined` | Currently selected value (`$bindable`) |
| `children` | `Snippet` | `undefined` | MenuRadioItem children |

### MenuRadioItem

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | `undefined` | This item's value |
| `disabled` | `boolean` | `false` | Whether the item is disabled |
| `children` | `Snippet` | `undefined` | Item label content |

### MenuGroup

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | `undefined` | Group heading label |
| `children` | `Snippet` | `undefined` | Group content |

### MenuSeparator

No props. Renders a visual divider between menu items.

## Events

### Menu (Container)

| Event | Detail | Description |
|-------|--------|-------------|
| `onopen` | none | Fires when the menu opens |
| `onclose` | none | Fires when the menu closes |

### MenuItem

| Event | Detail | Description |
|-------|--------|-------------|
| `onclick` | none | Fires when the item is clicked |

### MenuCheckboxItem / MenuRadioGroup

| Event | Detail | Description |
|-------|--------|-------------|
| `onchange` | `{ checked?: boolean, value?: string }` | Fires when the selection changes |

## Types

### MenuContext

```typescript
interface MenuContext {
  close_on_select: boolean;
  close: () => void;
  size: string;
  registerItem: (el: HTMLElement) => void;
  unregisterItem: (el: HTMLElement) => void;
}
```

## Accessibility

- Menu uses `role="menu"`, items use `role="menuitem"`
- Checkbox items use `role="menuitemcheckbox"` with `aria-checked`
- Radio items use `role="menuitemradio"` with `aria-checked`
- Groups use `role="group"` with `aria-labelledby`
- Separators use `role="separator"`
- **Arrow Down / Up** navigates between items
- **Home / End** jumps to first / last item
- **Enter / Space** activates the focused item
- **Escape** closes the menu
- Disabled items are excluded from keyboard navigation (`aria-disabled`)
- Focus is managed within the menu via Popover component
