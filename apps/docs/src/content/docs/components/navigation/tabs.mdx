## Import

Tabs uses a compound component pattern. The `Tab` and `TabContent` sub-components are re-exported from the same module.

```svelte
import { Tabs, Tab, TabContent } from '@delightstack/components';
import type { TabsContext } from '@delightstack/components';
```

## Basic Usage

<ComponentPreview code={`<script>
  import { Tabs, Tab, TabContent } from '@delightstack/components';

  let activeTab = $state('overview');
</script>

<Tabs bind:value={activeTab}>
  <Tab value="overview" label="Overview" />
  <Tab value="features" label="Features" />
  <Tab value="pricing" label="Pricing" />
</Tabs>

<TabContent value="overview">
  <p>Overview content goes here.</p>
</TabContent>
<TabContent value="features">
  <p>Features content goes here.</p>

<TabContent value="pricing">
  <p>Pricing content goes here.</p>

</ComponentPreview>

## Props

### Tabs (Container)

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | `''` | The currently selected tab value (`$bindable`) |
| `pills` | `boolean` | `false` | Use pill-shaped tab buttons |
| `boxed` | `boolean` | `false` | Use boxed tab style |
| `segment` | `boolean` | `false` | Use segmented-control style |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Tab list orientation |
| `size` | `'0' \| '1' \| '2' \| '3'` | `'1'` | Size of the tabs |
| `fullWidth` | `boolean` | `false` | Stretch tabs to fill available width |
| `disabled` | `boolean` | `false` | Disable all tabs |
| `skeleton` | `boolean` | `false` | Show skeleton loading state |
| `skeletonCount` | `number` | `3` | Number of skeleton tab placeholders |
| `id` | `string` | auto | Element ID |
| `class` | `string` | `''` | Additional CSS classes |
| `children` | `Snippet` | `undefined` | Tab children |

### Tab (Item)

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | `''` | The unique value for this tab |
| `label` | `string` | `''` | The label text for this tab |
| `badge` | `string \| number` | `undefined` | Badge displayed next to the label |
| `disabled` | `boolean` | `false` | Whether this individual tab is disabled |

### TabContent

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | `''` | The tab value this content panel belongs to |
| `children` | `Snippet` | `undefined` | Panel content (rendered only when the matching tab is active) |

## Events

### Tabs (Container)

| Event | Detail | Description |
|-------|--------|-------------|
| `onchange` | `{ value: string }` | Fires when the active tab changes |

## Types

### TabsContext

```typescript
interface TabsContext {
  value: string;
  pills: boolean;
  boxed: boolean;
  segment: boolean;
  size: string;
  orientation: 'horizontal' | 'vertical';
  disabled: boolean;
  select: (value: string) => void;
  register: (value: string, el: HTMLElement) => void;
  unregister: (value: string) => void;
}
```

## Accessibility

- Tab list uses `role="tablist"` with `aria-orientation`
- Each tab button uses `role="tab"` with `aria-selected` and `aria-controls`
- Tab content panels use `role="tabpanel"` with `aria-labelledby`
- **Arrow Left / Right** (or **Up / Down** for vertical) navigates between tabs
- **Home** / **End** jumps to the first / last tab
- **Enter / Space** activates the focused tab
- Disabled tabs are excluded from keyboard navigation (`aria-disabled`, `tabindex="-1"`)
- Sliding indicator animation highlights the active tab
- Focus-visible outlines on tab buttons
- Respects `prefers-reduced-motion` for indicator transitions
