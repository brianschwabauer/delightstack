DelightStack is a comprehensive **Svelte 5 component library** with 55 production-ready components across 6 categories. Every component is crafted with attention to detail, thoughtful micro-animations, and a cohesive visual language.

## Design Philosophy

- **Details Matter** — Every pixel, every transition, every interaction is intentional.
- **Delight Users** — Subtle animations, smooth transitions, and unexpected moments of joy.
- **Opinionated by Default** — Components look great out of the box with sensible defaults.
- **Modern CSS** — Plain CSS with custom properties, `light-dark()`, `color-mix()`, and container queries. No CSS-in-JS overhead.
- **Self-Contained** — Each component is readable and maintainable in a single file.

## Component Categories

### Actions
Interactive elements that trigger behaviors: **Button**, **ButtonGroup**, **Modal**, **Alert**, **Popover**, **ContextMenu**, **Portal**, **CommandPalette**, and **ThemeToggle**.

### Display
Components for presenting information: **Accordion**, **Avatar**, **AvatarGroup**, **Calendar**, **Chart**, **Code**, **Comparison**, **Counter**, **Expand**, **List**, **ListItem**, **QR**, **SplitPane**, **Stat**, **Table**, **Timeline**, **Tree**, and **Typewriter**.

### Feedback
Components that communicate state and progress: **Callout**, **Confetti**, **Progress**, and **Toaster** (toast notifications).

### Form
Input components for user data entry: **Input**, **Checkbox**, **Fieldset**, **FileUpload**, **Form** (with Standard Schema validation), **Radio**, **Range**, **Rating**, **Select**, and **Toggle**.

### Media
Rich media components: **Carousel**, **Gallery**, **Image**, **Map**, **Panorama**, **PDF**, and **Video**.

### Navigation
Components for moving through the application: **BottomSheet**, **Breadcrumbs**, **Drawer**, **Menu**, **Pagination**, **Steps**, and **Tabs**.

## How It Works

All 55 components are available from a single import path:

```svelte
<script>
  import { Button, Input, Modal } from '@delightstack/components';
</script>

<Button onclick={() => console.log('clicked!')}>
  Click Me
</Button>
```

Components use **callback props** (`onclick`, `onchange`) instead of dispatched events, support **two-way binding** via `bind:value`, and automatically handle loading states when callbacks return Promises.
