## Why DelightStack?

<CardGrid stagger>
	<Card title="55 Components" icon="puzzle">
		A comprehensive library covering actions, display, feedback, forms, media, and navigation — everything you need to build modern web apps.
	</Card>
	<Card title="Svelte 5 Native" icon="rocket">
		Built from the ground up with Svelte 5 runes (`$props`, `$state`, `$derived`, `$effect`), snippets, and the `{@attach}` directive.
	</Card>
	<Card title="Dark Mode Built-in" icon="moon">
		Every component supports light and dark mode out of the box using CSS `light-dark()` — no JavaScript theme switching required.
	</Card>
	<Card title="Accessible" icon="approve-check">
		ARIA attributes, keyboard navigation, focus management, and `prefers-reduced-motion` support are built into every component.
	</Card>
	<Card title="Design System Included" icon="seti:css">
		A complete set of CSS custom properties for colors, spacing, typography, shadows, and animations — fully customizable.
	</Card>
	<Card title="Zero Runtime Dependencies" icon="star">
		Components use plain CSS with modern features like `color-mix()`, container queries, and relative color syntax. No CSS-in-JS overhead.
	</Card>
</CardGrid>
